# 🧪 Automation Test Store - Selenium POM Framework

## 📌 Project Overview
This project is a Selenium Automation Framework developed using:
- Java
- Selenium WebDriver
- TestNG
- Maven
- Page Object Model (POM)
- Extent Reports
- GitHub Integration

The framework automates test cases for an e-commerce web application.

---

## 🏗️ Framework Architecture

- Page Object Model (POM)
- TestNG Test Execution
- Config-based Environment Handling
- Extent Report for HTML Reporting
- Maven for Dependency Management
